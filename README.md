# Team Dispatch v2.5.1

## 任務儀表板：當日休假人員顯示調整

本版屬於功能修改，因此版本由 v2.5.0 更新第三碼為 v2.5.1。

「當日休假人員」不再顯示：
- 休假時數
- 可用工時

改為顯示：
- 人員姓名
- 休假起始時間

例如：
- 王小明｜休假起始 13:00
- 陳小華｜整天休假 · 起始 00:00

如果同一人當天有多筆請假，顯示當天最早的一筆休假起始時間。
