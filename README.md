## 任務儀表板

### 到期警示
公開儀表板中的未結任務：
- 需求日 < 今天：顯示 `⚠ 已逾期`
- 需求日 = 今天：顯示 `⚠ 今日到期`

### 區塊名稱
`本週未結任務`

## 我的工作

### 已逾期未完工任務
登入載入工作資料時，若任務：
- status = accepted
- requestDate < 今天

系統會把該任務原本的 TaskAllocations 收斂成今天一筆：

`今天 = 預估總工時 plannedHours`

例如：
- 預估總工時 16h
- 原本 9/8 4h、9/9 6h、9/10 6h
- 今天 9/11，且需求日已逾期

會改成：
- 9/11 16h

任務一旦回報完成，Loading 仍依既有規則不再計算。

### 自己派工給自己的任務可修改需求日期
在任務詳細內容中，selfAssigned + accepted 任務會出現：
- 日期選擇器
- 更新需求日期

需求日期不可早於任務開始日。

若延後需求日：
- 保留目前已排好的 TaskAllocations
- 不自動增加額外排程

若縮短需求日，且原排程有落在新需求日之後：
- 超出的排程會移除
- 預估總工時不變
- 工時重新收斂在新需求日期範圍內
