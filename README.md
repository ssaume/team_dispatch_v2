# Team Dispatch v2.8.2

本版為任務內容視窗 UI/UX 修改，因此更新第三碼。

## 1. 手機檢視

手機寬度 640px 以下：

- 任務內容視窗改為全螢幕
- 不使用窄小 modal
- 標題列與關閉按鈕固定在頂部
- 內容本身獨立捲動
- 所有主要欄位改成單欄
- 更新按鈕改為滿寬，避免誤觸
- 日曆排程每一列在手機改為上下堆疊
- 工作日 / 工時輸入不會被壓縮
- input / select / textarea 使用 16px，避免 iOS Safari 點擊輸入框時自動放大
- 360px～380px 的窄手機，摘要卡會再降為單欄

## 2. 任務內容視窗重新整理

原本所有欄位都塞在一個 detail-grid。

v2.8.2 改成四個資訊層級：

### 任務摘要
第一眼顯示：
- 工作名稱
- 狀態
- 公開 / 私人
- 共同作業
- 需求日
- 預估工時
- 派工者
- 負責人

### 工作內容
保留：
- 工作類型
- 需求內容
- 更新工作內容

### 任務設定
預設收合，使用時展開：
- 任務類型 / 週期
- 需求日期
- 預估總工時
- 公開屬性
- 新增共同作業

### 日曆排程
維持直接編輯每日工時的方式，獨立成一張卡片。

### 歷程紀錄
預設收合：
- 建立時間
- 接單時間
- 完成時間
- 狀態
- 拒絕理由
- 中止理由

### 任務操作
中止 / 重新啟動移到最下面獨立區塊，與一般修改功能分開。

## 桌機

桌機仍為 modal：
- 寬度由原本約 620px 調整到最多 780px
- 不再使用左右 label/value 密集排列
- 區塊之間使用卡片式視覺層級
