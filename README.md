# Team Dispatch v2.5.0

## 版本規則
- 功能修改 / bug fix：第三碼
- 新增功能：第二碼

本版因新增「任務儀表板 → 當日休假人員」功能，因此版本由 v2.4.0 升為 v2.5.0。

## 1. 我的工作日曆：部分請假顯示 Loading

如果當日有請假但不是整天：

`可用工時 = 8h - 當日請假時數`

`Loading = 當日進行中任務工時 ÷ 可用工時`

例如：
- 請假 4h
- 可用 4h
- 當日進行中任務 2h

顯示：
`Loading 50%`

請假提示與「可用 4h」仍然顯示。

整天請假（可用 0h）：
- 不顯示 Loading %
- 顯示「整天請假・不可派工」

已完成任務不計入當日 Loading。

## 2. 團隊出勤：部分請假仍顯示 Loading

團隊出勤延續同一公式：

`Loading = 任務工時 ÷ (8h - 請假時數)`

只要剩餘可工作時數 > 0，就顯示 Loading。

例如：
- 請假 2h
- 可用 6h
- 任務 3h
- Loading = 50%

只有整天休假時不顯示 Loading chip。

## 3. 任務儀表板：當日休假人員

免登入任務儀表板新增：
`當日休假人員`

顯示：
- 人員姓名
- 整天休假
或
- 休假 Xh / 可用 Xh

不公開：
- 假別
- 請假原因
- 詳細起訖時間

例如：
- 王小明｜整天休假
- 陳小華｜休假 4h · 可用 4h
